## 🎨 Design Philosophy

> *"Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away."*
> — **Antoine de Saint-Exupéry**

I like Android interfaces that feel native, calm, and intentional. My current direction follows Material 3:

| | |
|---|---|
| **Color** | Semantic and purposeful |
| **Surfaces** | Layered instead of heavily shadowed |
| **Shapes** | Rounded, expressive, consistent |
| **Typography** | Strong hierarchy, restrained emphasis |
| **Motion** | Useful, fast, readable |
| **Dark mode** | Designed alongside light mode |
| **Dynamic color** | Supported whenever practical |

The goal isn't to make an interface look complicated. The goal is to make it feel like it belongs on the device.

---

## 🔐 Privacy Philosophy

> *"The right to be left alone is the most comprehensive of rights, and the right most valued by civilized men."*
> — **Louis Brandeis**

Privacy isn't a marketing line I add after development. I try to make it part of the architecture.

- No unnecessary internet access
- No unnecessary analytics
- No unnecessary tracking
- No unnecessary background work
- No unnecessary permissions

**Prefer:** local processing · offline-first design · minimal permissions · transparent behavior · small footprints.

When an app doesn't need the internet, I'd rather not give it internet access.
